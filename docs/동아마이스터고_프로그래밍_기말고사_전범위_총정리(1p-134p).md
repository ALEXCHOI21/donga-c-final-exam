# PART 01. 프로그래밍의 개요 (8p ~ 49p)

## 📌 CHAPTER 01. 프로그래밍 언어의 종류와 특징 (10p ~ 18p)

### 1. 핵심 개념 정리
- **프로그래밍 언어(Programming Language)**: 사람과 컴퓨터 사이의 대화를 가능하게 해 주는 언어로, 컴퓨터가 이해할 수 있는 형태의 프로그램을 작성하기 위한 도구.
- **저급 언어(Low-level Language)**:
  - 컴퓨터 하드웨어 중심의 언어로 실행 속도가 빠름.
  - **기계어(Machine Language)**: `0`과 `1`의 2진수로 구성. 컴퓨터가 직접 이해할 수 있는 유일한 언어. 작성과 디버깅이 극도로 어려움.
  - **어셈블리어(Assembly Language)**: 읽기 어려운 기계어 명령어를 사람이 이해하기 쉬운 **기호(니모닉, Mnemonic)**로 1:1 대응시킨 언어.
- **고급 언어(High-level Language)**:
  - 사람의 일상 언어(자연어, 영어)에 가까워 배우기 쉽고 작성하기 편함. 컴퓨터가 직접 이해하지 못하므로 번역 프로그램이 필요.
  - **절차 지향 언어(Procedural Language)**: 순차적인 실행 순서(절차)와 함수 중심.
    - 종류: **C, FORTRAN, COBOL, BASIC, Pascal, ALGOL, PL/1**
  - **객체 지향 언어(Object-Oriented Language)**: 데이터(속성)와 이를 처리하는 메서드(행위)를 하나로 묶은 객체(Object) 중심. 재사용성과 유지보수성이 뛰어남.
    - 종류: **C++, Java, Python, C#, Smalltalk, Simula, ADA**
- **객체 지향의 핵심 개념**:
  - **객체(Object)**: 현실 세계의 사물 (예: 동물, 자동차)
  - **속성(Attribute/Data)**: 상태 값 (예: 무게, 나이, 색상)
  - **행위(Behavior/Method)**: 동작, 기능, 함수 (예: 달린다, 숨쉰다, 멈춘다)

### 2. 4지선다형 시험 출제 포인트 & 함정
> [!IMPORTANT]
> - **출제 1순위**: 프로그래밍 언어의 분류 (절차 지향 언어 vs 객체 지향 언어 구분).
> - **함정**: C 언어는 **절차 지향 언어**이고, C++과 Java, Python은 **객체 지향 언어**라는 점을 혼동하지 말 것!
> - 어셈블리어는 고급 언어가 아니라 **저급 언어**에 속함!

① C, FORTRAN, COBOL  
② C++, Java, Python

## 📌 CHAPTER 02. 프로그래밍의 절차 (19p ~ 24p)

### 1. 핵심 개념 정리
- **프로그래밍의 7단계 순서 (교과서 20p ~ 21p)**:
  1. **문제 분석**: 요구 사항 파악, 입력 데이터와 출력 결과 검토, 개발 언어/시스템 선정.
  2. **입출력 설계**: 입력 매체/형식 결정, 처리 순서/방법 설계, 출력 장치/형식 결정.
  3. **순서도 작성**: 알고리즘을 기호 도표로 나타내어 로직 파악 및 오류 방지.
  4. **프로그램 작성(코딩, Coding)**: 설계에 맞춰 소스 코드 작성. 결과물을 **원시(소스) 프로그램**이라 함.
  5. **번역과 디버깅(Debugging)**: 번역기(컴파일러 등)를 통해 목적 코드로 번역하고, 오류(Syntax Error)를 찾아 수정.
  6. **프로그램 실행 및 테스트**: 모의 데이터로 실행하여 **논리 오류(Logic Error)** 검증 및 실제 데이터 실행.
  7. **평가와 문서화**: 효율성/경제성 분석 후 프로그램 설명서, 설계서, 매뉴얼 등을 작성.

- **언어 번역 프로그램 비교 (21p ~ 22p)**:
  | 구분 | 컴파일러 (Compiler) | 인터프리터 (Interpreter) | 어셈블러 (Assembler) |
  |:---|:---|:---|:---|
  | **번역 단위** | 프로그램 전체를 한 번에 번역 | 프로그램을 한 줄(행)씩 번역 | 어셈블리어 명령 단위 |
  | **목적 프로그램** | **생성함 (`.obj`)** | **생성하지 않음** | 생성함 (`.obj`) |
  | **번역 속도** | 느림 | 빠름 | 빠름 |
  | **실행 속도** | **빠름 (효율적)** | **느림** | 매우 빠름 |
  | **필요 메모리** | 많이 차지함 | 적게 차지함 | 적음 |
  | **대표 언어** | **C, C++, Java** | **Python, BASIC, JavaScript** | 어셈블리어 |

### 2. 4지선다형 시험 출제 포인트 & 함정
> [!WARNING]
> - **순서 배열 문제**: `문제 분석 → 입출력 설계 → 순서도 작성 → 프로그램 작성(코딩) → 번역/디버깅 → 실행 → 평가/문서화`
> - **컴파일러 vs 인터프리터 차이**: "인터프리터는 목적 프로그램을 생성한다"는 오답 보기가 시험에 단골 출제됨! (인터프리터는 목적 프로그램을 만들지 않고 바로 실행함).

### 3. 실전 4지선다형 예상 문제
**Q2. 언어 번역 프로그램인 컴파일러(Compiler)와 인터프리터(Interpreter)에 대한 설명 중 옳은 것은?**  
① 인터프리터는 프로그램 전체를 한 번에 기계어로 번역하여 목적 파일을 생성한다.  
② 컴파일러는 한 줄씩 번역하면서 즉시 실행하므로 전체 실행 속도가 인터프리터보다 느리다.  
③ 인터프리터는 목적 프로그램을 생성하지 않고 즉시 실행하므로 번역 속도는 빠르지만 실행 속도는 느리다.  
④ C 언어는 대표적인 인터프리터 언어이다.  
* **정답**: ③  
* **해설**: 인터프리터는 목적 프로그램을 만들지 않고 행 단위로 번역/실행하므로 번역은 빠르나 반복 실행 속도는 느리다. C 언어는 컴파일러 언어이다.

## 📌 CHAPTER 03. 알고리즘 (25p ~ 34p)

### 1. 핵심 개념 정리
- **알고리즘(Algorithm)**: 어떤 문제를 해결하기 위한 명확한 절차와 단계적 방법.
- **알고리즘의 5대 필요 조건 (26p)**:
  1. **입력(Input)**: 외부에서 제공되는 자료가 **0개 이상** 존재해야 함.
  2. **출력(Output)**: 처리된 결과가 **최소 1개 이상** 반드시 나와야 함.
  3. **명확성(Definiteness)**: 각 명령어의 의미는 애매모호하지 않고 명확해야 함.
  4. **유한성(Finiteness)**: 일정한 단계를 거친 후 **반드시 종료**되어야 함 (무한 루프 방지).
  5. **유효성/수행 가능성(Effectiveness)**: 모든 명령어는 종이와 연필로도 수행할 수 있을 정도로 컴퓨터에서 실행 가능해야 함.

- **알고리즘의 표현 방법 4가지 (27p)**:
  - 자연어(Natural Language), 의사 코드(Pseudo Code), 순서도(Flowchart), 프로그래밍 언어.

- **순서도(Flowchart) 표준 기호 (29p ~ 31p)**:
  | 기호 모양 | 명칭 | 기능 및 용도 |
  |:---:|:---:|:---|
  | ⬭ (모서리 둥근 사각형/타원) | **단말 (Terminal)** | 프로그램의 시작(Start)과 끝(End/Stop) |
  | ▱ (평행사변형) | **입출력 (Input/Output)** | 데이터의 입력(Input) 및 결과의 출력(Print) |
  | ▭ (직사각형) | **처리 (Process)** | 연산, 계산, 값의 대입 등 일반적인 처리 |
  | ◇ (마름모) | **판단/조건 (Decision)** | 조건 검사 및 분기 (참/거짓 또는 Yes/No에 따른 경로 선택) |
  | ⬡ (육각형) | **준비 (Preparation)** | 변수의 선언 및 초깃값 설정 |
  | ◯ (작은 원) | **연결자 (Connector)** | 동일 페이지 내에서 복잡한 선을 연결할 때 사용 |
  | $\rightarrow$ (화살표 선) | **흐름선 (Flowline)** | 처리의 실행 순서와 방향 |

- **순서도의 3대 기본 구조 (34p)**:
  - **순차형**: 위에서 아래로 순서대로 실행.
  - **선택형(분기형)**: 조건 판단에 따라 실행 경로 분기.
  - **반복형**: 조건이 만족될 때까지 일정 블록을 되풀이 실행.

### 2. 4지선다형 시험 출제 포인트 & 함정
> [!IMPORTANT]
> - 순서도 기호 연결 문제: 마름모(조건 판단), 평행사변형(입출력), 직사각형(처리/연산), 타원(시작/끝).
> - 알고리즘 조건: 입력은 0개 이상 가능하지만, **출력은 반드시 1개 이상**이어야 함!

### 3. 실전 4지선다형 예상 문제
**Q3. 알고리즘의 성립 조건에 대한 설명으로 옳지 않은 것은?**  
① 입력은 반드시 1개 이상 외부에서 주어져야만 한다.  
② 최소한 하나 이상의 유효한 출력이 도출되어야 한다.

④ 각 명령어는 컴퓨터에서 실제로 수행 가능한 유효성을 지녀야 한다.

## 📌 CHAPTER 04. 프로그래밍 개발 환경 (35p ~ 49p)

### 1. 핵심 개념 정리
- **통합 개발 환경(IDE, Integrated Development Environment)**:
  - 프로그램 개발에 필요한 **에디터(Editor, 소스 작성)**, **컴파일러(Compiler, 번역)**, **디버거(Debugger, 오류 수정)**를 하나의 소프트웨어 프로그램으로 통합하여 제공하는 환경. (예: Visual Studio, Code::Blocks, Eclipse).
- **C 언어의 주요 특징 (48p)**:
  - 데니스 리치가 벨 연구소에서 UNIX 운영체제를 만들기 위해 개발.
  - 시스템 프로그래밍과 응용 프로그래밍 모두에 적합.
  - 함수 중심의 절차 지향 언어로, 구조적 프로그래밍 가능.
  - 하드웨어를 직접 제어할 수 있는 포인터 연산 지원.
  - 처리 속도가 빠르고 이식성(Portability)이 뛰어남.
- **C 프로그램 빌드(Build) 과정**:
  - `소스 파일(.c, .cpp)` $\xrightarrow{\text{전처리기 & 컴파일러}}$ `목적 파일(.obj)` $\xrightarrow{\text{링커(Linker) & 라이브러리 결합}}$ `실행 파일(.exe)` $\xrightarrow{\text{로더(Loader)}}$ `메모리 적재 후 실행`.
- **오류(Error)의 3가지 유형**:
  1. **컴파일 오류 (구문 오류, Syntax Error)**:
     - 문법 규칙 위반 (세미콜론 누락, 예약어 오타, 괄호 짝 불일치 등). 컴파일러가 잡아냄.
  2. **런타임 오류 (Runtime Error)**:
     - 프로그램 실행 중에 비정상적으로 종료되는 오류 (0으로 나누기, 잘못된 메모리 주소 접근 등).
  3. **논리 오류 (Logic Error)**:
     - 문법 오류 없이 실행은 정상적으로 되나, 프로그래머의 알고리즘 잘못으로 **원하지 않는 엉뚱한 결과가 나오는 오류**.

### 2. 4지선다형 시험 출제 포인트 & 함정
> [!TIP]
> - 파일 확장자 변환 순서: `.c` (소스 파일) $\rightarrow$ `.obj` (목적 파일) $\rightarrow$ `.exe` (실행 파일).
> - 링커(Linker)의 역할: 목적 파일들을 라이브러리와 묶어 실행 파일(`.exe`)로 만드는 소프트웨어.
> - 로더(Loader)의 역할: 하드디스크의 실행 파일을 메모리에 로드(적재)시키는 소프트웨어.

### 3. 실전 4지선다형 예상 문제
**Q4. C 언어 프로그램의 작성 및 실행 과정에서 생성되는 파일의 확장자 변화 순서로 올바른 것은?**

## 📌 CHAPTER 01. 변수와 자료형 (52p ~ 78p)

### 1. 핵심 개념 정리
- **C 프로그램의 기본 구조**:
  ```c
  #include <stdio.h> // 전처리기 지시자 (헤더 파일 포함)
  int main(void) {   // 프로그램의 시작 진입점인 main 함수 (반드시 1개 존재)
      // 변수 선언 및 실행 문장 (세미콜론 ; 으로 끝남)
      return 0;      // 운영체제에 정상 종료(0) 신호 반환
  }
  ```
  - C 프로그램은 **반드시 하나 이상의 함수**를 포함해야 하며, 실행은 **`main()` 함수**에서 시작된다.
  - 실행 문장의 끝에는 반드시 **세미콜론(`;`)**을 붙인다.
  - 주석(Comment): `//` (한 줄 주석), `/* ... */` (여러 줄 주석). 컴파일러가 무시함.

- **식별자(변수명, 함수명) 명명 규칙 (57p ~ 58p, ★★★ 시험 단골)**:
  1. 영문자(A~Z, a~z), 숫자(0~9), 밑줄(`_`)로만 구성된다.
  2. **첫 글자는 반드시 영문자이거나 밑줄(`_`)이어야 하며, 숫자로 시작할 수 없다!** (예: `2start` ❌, `_start` ⭕).
  3. **대문자와 소문자를 엄격히 구별한다** (예: `Sum`과 `sum`은 완전히 다른 변수).
  4. C 언어의 **예약어(키워드)**는 식별자로 사용할 수 없다 (예: `int`, `return`, `for`, `double` ❌).
  5. 공백(스페이스)이나 특수문자(`$`, `#`, `@` 등)는 포함될 수 없다 (예: `a bc` ❌).

  |:---|:---:|:---|:---|:---:|
  | **`char`** | **1 Byte** | 문자, 작은 정수 | -128 ~ 127 (ASCII 코드) | `%c` |
  | `unsigned char` | 1 Byte | 부호 없는 문자 | 0 ~ 255 | `%u` |
  | `short` | 2 Byte | 정수형 | -32,768 ~ 32,767 | `%d` |
  | **`int`** | **4 Byte** | 기본 정수형 | 약 -21억 ~ +21억 | `%d` |
  | `unsigned int` | 4 Byte | 부호 없는 정수 | 0 ~ 약 42억 | `%u` |
  | `long` | 4 Byte | 긴 정수형 | -21억 ~ +21억 | `%ld` |
  | **`float`** | **4 Byte** | 단정도 실수형 | 유효자리 6자리 내외 | `%f` |
  | **`double`** | **8 Byte** | 배정도 실수형 | 유효자리 15자리 내외 | `%f`, `%lf` |

- **상수(Constant)**:
  - 정수 상수: 10진수(100), 8진수(`0`으로 시작, 예: `012`), 16진수(`0x`로 시작, 예: `0x1F`).

  - 문자열 상수: 큰따옴표(`" "`), 널 문자(`\0`)가 끝에 자동으로 추가됨 (예: `"Hello"`).

## 📌 CHAPTER 02. 입출력 함수 (79p ~ 92p)

### 1. 핵심 개념 정리
- **표준 입출력 헤더**: `#include <stdio.h>` (`standard input output`의 약어).
- **표준 출력 함수 `printf()`**:
  - 기본 형식: `printf("서식문자열", 인수1, 인수2, ...);`
  - **형식 지정 문자 (81p, ★★★)**:
    - `%d`: 10진수 정수 출력
    - `%f`: 부동 소수점 실수 출력 (기본 소수점 이하 6자리까지 출력)
    - `%c`: 문자 1개 출력
    - `%s`: 문자열 출력
    - `%x`, `%X`: 16진수 정수 출력 (소문자/대문자)
    - `%o`: 8진수 정수 출력
    - `%u`: 부호 없는(unsigned) 10진수 출력
    - `%e`, `%E`: 지수 형식 실수 출력
  - **출력 자릿수 제어 (82p)**:
    - `%5d`: 전체 5칸 확보, **오른쪽 정렬** (남는 앞 공간은 빈칸).
    - `%-5d`: 전체 5칸 확보, **왼쪽 정렬** (남는 뒷 공간은 빈칸).
    - `%.2f`: 소수점 이하 둘째 자리까지 출력 (**셋째 자리에서 반올림**).
    - `%9.2f`: 전체 9칸 확보(소수점 포함), 오른쪽 정렬, 소수점 이하 둘째 자리까지 출력.
  - **제어 문자 (이스케이프 시퀀스, Escape Sequence)**:
    - `\n`: 줄 바꿈 (개행, New Line)
    - `\t`: 수평 탭 (일정 간격 띄움)
    - `\\`: 역슬래시(`\`) 자체 출력
    - `%%`: 퍼센트(`%`) 자체 출력
    - `\"`: 큰따옴표 출력

- **단일 문자 및 문자열 입출력 전용 함수 (83p ~ 86p)**:
  - 문자 1개: `putchar(c)` (출력), `c = getchar()` (입력)
  - 문자열: `puts(str)` (출력 후 자동 줄바꿈), `gets_s(str, size)` (입력)

- **표준 입력 함수 `scanf()` 및 `scanf_s()` (84p ~ 87p, ★★★ 시험 단골)**:
  - 기본 형식: `scanf_s("%d", &변수명);`
  - **주소 연산자 `&` (Ampersand)**: 입력받은 데이터를 변수의 메모리 공간에 직접 저장해야 하므로 **변수명 앞에 반드시 주소 연산자 `&`를 붙여야 함!** (`&`를 누락하면 런타임/디버그 에러 발생!).
  - (단, 문자열 배열명 앞에는 `&`를 붙이지 않음).

### 2. 4지선다형 시험 출제 포인트 & 함정
> [!WARNING]
> - `scanf_s("%d", a);` $\rightarrow$ 에러 원인: `a` 앞에 `&`가 빠짐!
> - `printf("%.2f\n", 1.235);` $\rightarrow$ 출력 결과: 셋째 자리 5가 반올림되어 `1.24` 출력!
> - `printf("%5d\n", 123);` $\rightarrow$ 공백 2칸 + 123 (`  123`).

## 📌 CHAPTER 03. 연산자 (93p ~ 113p)

### 1. 핵심 개념 정리
- **피연산자 수에 따른 분류**:
  - 단항 연산자: 피연산자 1개 (`++`, `--`, `!`, `~`, `sizeof`, 부호 `+`, `-`)
  - 이항 연산자: 피연산자 2개 (산술, 관계, 논리, 대입 등 대다수)
  - 삼항 연산자: 피연산자 3개 (`(조건) ? 참 : 거짓`)

- **연산자 우선순위 및 결합 방향 (95p, ★★★ 표 Ⅱ-8 암기)**:
  | 우선순위 | 연산자 종류 | 대표 연산자 | 결합 방향 |
  |:---:|:---|:---|:---:|
  | **1위 (최고)** | 괄호, 배열, 구조체 | `()`, `[]`, `.`, `->` | 좌 $\rightarrow$ 우 |
  | **2위** | **단항 연산자** | `!`, `~`, `++`, `--`, `+`, `-`, `sizeof`, `&`, `*` | **우 $\rightarrow$ 좌 (←)** |
  | **3위** | 산술 (곱셈/나눗셈) | `*`, `/`, `%` | 좌 $\rightarrow$ 우 |
  | **4위** | 산술 (덧셈/뺄셈) | `+`, `-` | 좌 $\rightarrow$ 우 |
  | **5위** | 시프트 연산자 | `<<`, `>>` | 좌 $\rightarrow$ 우 |
  | **6위** | 관계 연산자 (대소) | `<`, `<=`, `>`, `>=` | 좌 $\rightarrow$ 우 |
  | **7위** | 관계 연산자 (동등) | `==`, `!=` | 좌 $\rightarrow$ 우 |
  | **8~10위** | 비트 논리 연산자 | `&` (AND) $\rightarrow$ `^` (XOR) $\rightarrow$ `|` (OR) | 좌 $\rightarrow$ 우 |
  | **11위** | **논리곱 (AND)** | `&&` | 좌 $\rightarrow$ 우 |
  | **12위** | **논리합 (OR)** | `||` | 좌 $\rightarrow$ 우 |
  | **13위** | **조건 (삼항)** | `? :` | **우 $\rightarrow$ 좌 (←)** |
  | **14위** | **대입 / 복합 대입** | `=`, `+=`, `-=`, `*=`, `/=`, `%=` | **우 $\rightarrow$ 좌 (←)** |
  | **15위 (최하)** | 콤마 연산자 | `,` | 좌 $\rightarrow$ 우 |

- **주요 연산자별 핵심 문법 및 계산 규칙**:
  1. **산술 연산자 (`+`, `-`, `*`, `/`, `%`)**:
     - 정수 나눗셈: `5 / 2` $\rightarrow$ 몫인 `2` (소수점 버림).
     - 실수 나눗셈: `5.0 / 2` $\rightarrow$ `2.5`.
     - **나머지 연산자 (`%`)**: **피연산자가 반드시 정수형이어야 함!** (실수형 `5.2 % 2`는 컴파일 에러!).
  2. **증감 연산자 (`++`, `--`, ★★★ 출제 1순위)**:
     - **전위형 (`++a`)**: 먼저 변수 값을 1 증가시킨 후, 그 증가된 값을 수식에 사용.
     - **후위형 (`a++`)**: 현재 변수 값을 수식에 먼저 사용한 후, 수식 처리가 끝나면 변수 값을 1 증가.
     - 예: `int a = 5, b;`
       - `b = ++a;` $\rightarrow$ `a=6, b=6`
       - `b = a++;` $\rightarrow$ `a=6, b=5`
  3. **관계 연산자 (`==`, `!=`, `>`, `<`, `>=`, `<=`)**:
     - 결과는 참이면 `1`, 거짓이면 `0`.
     - 같다는 기호는 `=`이 아니라 **`==`** 임!
  4. **논리 연산자 (`&&`, `||`, `!`)**:
     - `&&` (AND): 둘 다 참(1)일 때만 결과 1.
     - `||` (OR): 둘 중 하나라도 참(1)이면 결과 1.
     - `!` (NOT): 참이면 0, 거짓이면 1로 반전.
     - **단락 평가(Short-circuit Evaluation)**: `&&`에서 앞 조건이 거짓이면 뒤 조건은 검사조차 안 함; `||`에서 앞 조건이 참이면 뒤 조건은 검사 안 함.
  5. **복합 대입 연산자**:
     - `a += b;` $\rightarrow$ `a = a + b;`
     - `a *= b + 1;` $\rightarrow$ `a = a * (b + 1);` (우변 전체를 먼저 계산 후 곱함에 주의!).
  6. **비트 연산자**:
     - `&` (비트 AND), `|` (비트 OR), `^` (비트 XOR, 다르면 1), `~` (비트 NOT), `<<` (왼쪽 시프트, $2^n$배 곱셈), `>>` (오른쪽 시프트, $2^n$배 나눗셈).

### 2. 4지선다형 시험 출제 포인트 & 함정
> [!WARNING]
> - `5 / 2`의 결과는 `2` (정수 나눗셈이므로 2.5가 아님!).
> - `a % b`에서 `a`나 `b`가 실수이면 에러!
> - 결합 방향이 **우측에서 좌측($\leftarrow$)**인 연산자 3가지: **단항 연산자, 삼항 조건 연산자, 대입 연산자**.

### 3. 실전 4지선다형 예상 문제
**Q7. 다음 C 언어 코드를 실행한 후 변수 `a`와 `b`에 저장되는 값으로 옳은 것은?**
```c
int x = 10, y = 10;
int a = ++x;
int b = y++;
```
① `a = 11, b = 11`  
② `a = 11, b = 10`  
③ `a = 10, b = 11`  
④ `a = 10, b = 10`  
* **정답**: ②  
* **해설**: `++x`는 전위 증가이므로 x가 11이 된 후 a에 11이 대입된다. `y++`는 후위 증가이므로 현재 y값인 10이 b에 먼저 대입된 후 y가 11로 증가한다. 따라서 `a = 11, b = 10`이다.

## 📌 CHAPTER 04. 제어문 (114p ~ 134p)

### 1. 01 제어문의 이해 (115p)
- **제어의 3대 구조**: 순차적 흐름, 선택(분기)적 흐름, 반복적 흐름.
- **제어문의 3대 분류**:
  - 조건문: `if`, `switch ~ case`
  - 반복문: `for`, `while`, `do ~ while`
  - 이동문(분기문): `break`, `continue`, `goto`

### 2. 02 조건문 (116p ~ 123p)
- **단순 if문 (116p ~ 118p)**:
  - 조건식이 참(0이 아님)이면 실행, 거짓(0)이면 건너뜀.
  - 실행 문장이 1문장이면 `{ }` 생략 가능, 2문장 이상이면 `{ }` 필수.
  - 여러 개의 단순 if문을 나열하면 모든 조건을 검사하므로 **시간 손실(비효율)** 발생.
- **다중 if문 (119p ~ 120p, `if ~ else if ~ else`)**:
  - 위에서부터 검사하여 처음 참이 되는 블록 1개만 실행 후 전체 제어문 즉시 탈출.
- **중첩 if문 및 삼항 조건 연산자 변환 (121p)**:
  - `(조건식) ? 참일 때 실행문 : 거짓일 때 실행문;`
  - `if(eng >= 60) printf("Pass\n"); else printf("Fail\n");` $\rightarrow$ `(eng >= 60) ? printf("Pass\n") : printf("Fail\n");`
- **switch ~ case문 (122p ~ 123p, ★★★ 4지선다 출제 1순위)**:
  1. `switch(식)`의 식에는 **정수형 변수/수식, 문자형만 가능 (실수 float/double 절대 불가!)**.
  2. `case` 뒤에는 반드시 **상수만 올 수 있음 (변수나 범위 비교 불가)**.
  3. `break;`가 없으면 아래 case 문장을 break를 만날 때까지 모두 실행 (**Fall-through**).
  4. `default:`는 if문의 `else`에 해당하며 일치하는 case가 없을 때 실행 (생략 가능).

### 3. 03 반복문 (123p ~ 131p)
- **반복문의 용도 구분 (<표 Ⅱ-16>, 123p)**:
  - **for문**: **횟수가 정해진 반복** (예: 5번 출력, 구구단 출력).
  - **while / do~while문**: **조건에 따른 횟수가 정해지지 않은 반복** (예: 합이 100 이상일 때까지).
- **단순 for문 (124p ~ 125p)**:
  - 형식: `for (초깃값; 조건식; 증감식) { 처리문장; }`
  - `for( ; ; )`처럼 수식을 생략하면 항상 참이 되어 **무한 루프** 발생.
  - **★ 루프 탈출 후 변수의 최종값**: `for(a=1; a<=5; a++)` 탈출 시 `a`의 값은 **`6`**!
- **중첩 for문 (126p ~ 127p)**:
  - 총 반복 횟수 = (외부 루프 회수) $\times$ (내부 루프 회수).
- **단순 while문 (127p ~ 128p)**:
  - **선(先) 검사 후(後) 실행**: 처음 조건이 거짓이면 본문 **0회 실행**.
  - 내부에 조건을 변화시키는 문장(증감식 등)이 없으면 무한 루프에 빠짐.
- **do ~ while문 (130p ~ 131p, ★★★ 시험 빈출)**:
  - **선(先) 실행 후(後) 검사**: 조건이 처음부터 거짓이라도 **무조건 최소 1회 실행**.
  - 문법 주의: `do { ... } while(조건식);` 맨 끝에 **반드시 세미콜론(`;`)이 붙음**.

### 4. 04 이동문 (131p ~ 134p)
- **break문 (131p ~ 132p)**:
  - 속해 있는 반복문이나 `switch`문을 **강제 탈출**.
  - 중첩 반복문에서 실행 시 **가장 가까운 1개의 반복문만 탈출** (프로그램 종료가 아님!).
- **continue문 (132p ~ 133p)**:
  - 반복문을 탈출하는 것이 아니라, **현재 회차의 남은 실행문을 건너뛰고(skip) 다음 반복 단계로 즉시 이동**.
  - for문에서는 **증감식**으로 이동, while/do~while문에서는 **조건식**으로 이동.
  - switch문에서는 사용 불가.
- **goto문 (134p)**:
  - 지정한 레이블(Label) 위치로 무조건 직접 점프.
  - 프로그램 구조를 파괴(스파게티 코드)하여 가독성과 유지보수성을 크게 떨어뜨리므로 **사용을 적극 권장하지 않음(지양)**.

### 2. C 언어 기본 자료형 크기
| 자료형 | 크기 | 서식 지정자 | 특징 |
|:---|:---:|:---:|:---|
| `char` | 1 Byte | `%c` | 1개 문자, 작은 정수 (-128 ~ 127) |
| `int` | 4 Byte | `%d` | 기본 정수형 (-21억 ~ 21억) |
| `float` | 4 Byte | `%f` | 단정도 실수 (소수점 6자리 유효) |
| `double` | 8 Byte | `%f`, `%lf` | 배정도 실수 (소수점 15자리 유효) |

### 3. 반복문 3종 비교
| 구분 | for문 | while문 | do ~ while문 |
|:---|:---|:---|:---|
| 적합한 상황 | 횟수가 정해진 반복 | 조건에 따른 반복 | 조건에 따른 반복 |
| 조건 검사 시점 | 선(先) 검사 | 선(先) 검사 | **후(後) 검사** |
| 최소 실행 횟수 | 0회 가능 | 0회 가능 | **무조건 최소 1회 실행** |
| 끝 세미콜론 | 없음 | 없음 | **`while(조건식);` 필수** |

### 4. 이동문 3종 비교
| 구분 | `break;` | `continue;` | `goto 레이블;` |
|:---|:---|:---|:---|
| 주요 동작 | 루프 또는 switch 블록 완전 탈출 | 이번 회차 건너뛰고 다음 회차로 진행 | 레이블 위치로 무조건 점프 |
| 이동 위치 | 블록 바깥 다음 문장 | for: 증감식 / while: 조건식 | 지정된 레이블 |
| 사용 평가 | 필수 및 권장 | 필요 시 권장 | **가독성 저해로 사용 비권장** |

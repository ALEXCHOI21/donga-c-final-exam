## 💡 주요 기능

1. **단원별 핵심 이론 & 함정 분석**: 교과서 본문, 표, TIP 박스를 망라한 페이지별 완벽 정리
2. **실전 4지선다형 20제 모의평가**: 문제 풀이 시 즉각적인 채점, 실시간 점수 집계, 상세 해설 노출
3. **교사 강의 모드 토글**: 클릭 한 번으로 모든 문제의 정답과 해설을 일괄 표시/가리기 가능 (교실 프로젝터 수업용)
4. **실시간 검색 & 인쇄 모드**: 원하는 키워드 즉시 필터링 및 A4 인쇄용 스타일 자동 적용

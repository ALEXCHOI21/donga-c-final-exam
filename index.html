📘 PART 01. 프로그래밍의 개요 (10p ~ 49p)

교과서 Chapter 01 ~ Chapter 04

10p~18p CHAPTER 01. 프로그래밍 언어의 종류와 특징

출제 1순위: 언어 분류

1. 저급 언어 vs 고급 언어

저급 언어: 하드웨어 중심, 빠른 실행 속도.

  • 기계어: 0과 1의 2진수. 컴퓨터가 직접 실행 가능한 유일한 언어. 디버깅 극히 어려움.
  • 어셈블리어: 기계어를 사람이 읽을 수 있는 기호(니모닉)로 1:1 대응시킨 저급 언어.

고급 언어: 사람의 자연어/영어 중심. 배우기 쉽고 이식성 높음.

2. 절차 지향 vs 객체 지향 언어 (핵심 암기)

절차 지향: 실행 절차와 순서 중심.

C, FORTRAN, COBOL, BASIC, Pascal, ALGOL

객체 지향: 데이터(속성) + 함수(행위) = 객체(Object) 중심.

C++, Java, Python, C#, Smalltalk, Simula, ADA
⚠️ 함정: C언어는 객체지향이 아니라 "절차 지향"입니다!

19p~24p CHAPTER 02. 프로그래밍의 절차 및 번역기

출제: 순서배열 & 번역기비교

프로그래밍 7단계 순서 (20p ~ 21p)

1. 문제 분석 $\rightarrow$ 2. 입출력 설계 $\rightarrow$ 3. 순서도 작성 $\rightarrow$ 4. 코딩 (소스작성) $\rightarrow$ 5. 번역 & 디버깅 $\rightarrow$ 6. 실행 & 테스트 $\rightarrow$ 7. 평가 & 문서화
구분 컴파일러 (Compiler) 인터프리터 (Interpreter)
번역 단위 프로그램 전체를 한 번에 번역 한 줄(행)씩 번역하며 즉시 실행
목적 파일 생성함 (.obj) 생성하지 않음 (단골 오답 함정!)
실행 속도 빠름 느림
대표 언어 C, C++, Java Python, JavaScript, BASIC

25p~34p CHAPTER 03. 알고리즘 & 순서도 표준 기호

출제: 5대조건 & 기호매칭

알고리즘의 5대 조건 (26p)

  1. 입력 (Input): 외부 입력은 0개 이상 존재.
  2. 출력 (Output): 처리 결과는 반드시 1개 이상 도출.
  3. 명확성 (Definiteness): 각 명령어는 모호함 없이 명확.
  4. 유한성 (Finiteness): 한정된 단계 후 반드시 종료.
  5. 유효성 (Effectiveness): 모든 연산은 컴퓨터가 실행 가능.

순서도(Flowchart) 핵심 기호 (29p)

⬭ 타원: 단말 (시작/종료)
▱ 평행사변형: 데이터 입출력
▭ 직사각형: 처리 및 연산
◇ 마름모: 조건 판단 및 분기

기본 3대 구조: 순차형, 선택형(분기형), 반복형

35p~49p CHAPTER 04. C 개발 환경 & 빌드 과정과 오류

출제: 확장자변환 & 에러유형

C 프로그램 빌드 파이프라인 (확장자 변화)

소스 파일 (.c, .cpp)
$\xrightarrow{\text{전처리기 & 컴파일러}}$
목적 파일 (.obj)
$\xrightarrow{\text{링커(Linker)}}$
실행 파일 (.exe)
$\xrightarrow{\text{로더(Loader)}}$
메모리 적재 & 실행
1. 구문/컴파일 오류

세미콜론 누락, 오타 등 C 문법 위반. 컴파일러가 발견.

2. 런타임 오류

0으로 나누기, 잘못된 주소 접근 등 실행 중 비정상 종료.

3. 논리 오류 (Logic)

문법 오류 없이 실행되나 결과가 잘못 나오는 알고리즘 실수.

52p~78p CHAPTER 01. 변수와 자료형

출제: 식별자규칙 & 크기

식별자(변수명) 5대 명명 규칙 (57p ~ 58p)

  • 영문자, 숫자, 밑줄(`_`)로만 구성된다.
  • 첫 글자는 반드시 영문자이거나 밑줄(`_`)이어야 하며 숫자 시작 불가.
  • 대문자와 소문자를 엄격히 구분한다 (`Score` $\neq$ `score`).
  • C 언어 예약어(키워드) 사용 불가 (`int`, `for`, `return` 등).
  • 공백 및 특수문자(`$`, `@`, `-` 등) 사용 불가.
❌ 불가: 2start, my-score, int, a bc
⭕ 가능: _count, start2, my_score, Student1

기본 자료형 크기 및 서식 (69p)

char: 1 Byte (`%c`)
int: 4 Byte (`%d`)
float: 4 Byte (`%f`)
double: 8 Byte (`%f`, `%lf`)

상수 표기: 10진수(10), 8진수(`012`), 16진수(`0x1A`), 문자(`'A'`), 문자열(`"Hello"`, 끝에 `\0` 자동 추가)

79p~92p CHAPTER 02. 입출력 함수 (printf & scanf_s)

출제: scanf & 누락 & 서식

printf 출력 형식 및 자릿수 제어 (81p ~ 82p)

  • `%5d`: 5칸 확보 후 오른쪽 정렬 (` 123`)
  • `%-5d`: 5칸 확보 후 왼쪽 정렬 (`123 `)
  • `%.2f`: 소수 둘째 자리까지 출력 (셋째 자리 반올림!)
  • `\n` (개행), `\t` (탭), `\\` (역슬래시), `%%` (% 출력)
printf("%.2f\n", 1.235); $\rightarrow$ 1.24 출력

scanf_s 입력과 주소 연산자 & (84p ~ 87p)

키보드로 값을 입력받아 변수에 저장할 때는 변수의 메모리 주소를 넘겨주어야 하므로 반드시 &를 붙여야 함!

❌ scanf_s("%d", num); $\rightarrow$ 디버그 런타임 에러 발생!
⭕ scanf_s("%d", &num); $\rightarrow$ 정상 작동

문자 전용: `putchar()`, `getchar()` / 문자열: `puts()`, `gets_s()`

93p~113p CHAPTER 03. 연산자 및 우선순위

출제: 전위/후위 & 우선순위

증감 연산자 전위 vs 후위 (핵심 킬러 문제)

  • 전위 증가 (`++a`): 먼저 변수 값을 1 증가시킨 후 수식에 사용.
  • 후위 증가 (`a++`): 현재 변수 값을 수식에 먼저 사용한 후, 나중에 변수 값 1 증가.
int a = 5, b = ++a; $\rightarrow$ a=6, b=6
int a = 5, b = a++; $\rightarrow$ a=6, b=5

산술 및 논리 연산자 필수 규칙

  • 정수 나눗셈: `5 / 2` $\rightarrow$ 2 (소수점 버림)
  • 나머지 연산자 (`%`): 피연산자가 반드시 정수형이어야 함! (실수 `%`는 문법 에러)
  • 논리 연산자: `&&` (둘 다 참), `||` (하나라도 참), `!` (부정)
  • 단락 평가: `&&`에서 앞 조건이 거짓이면 뒤 조건은 실행조차 안 함!
⭐ 우선순위 & 결합방향: 단항(`! ++ --`) $\rightarrow$ 산술(`* / %` $\rightarrow$ `+ -`) $\rightarrow$ 관계(`> < == !=`) $\rightarrow$ 논리(`&&` $\rightarrow$ `||`) $\rightarrow$ 조건(`?:`) $\rightarrow$ 대입(`= +=`).
⚠️ 결합방향이 우측에서 좌측($\leftarrow$)인 연산자: 단항 연산자, 삼항 조건 연산자, 대입 연산자.

114p~134p CHAPTER 04. 제어문 (조건문 · 반복문 · 이동문)

기말고사 하이라이트

1. 조건문 (if & switch)

  • 단순 if: 1줄일 때 `{ }` 생략 가능
  • 다중 if: 첫 참 조건 1개만 실행 후 탈출
  • switch~case 4대 규칙:
    1. 식에는 정수/문자만 (실수 절대 불가)
    2. case 값은 상수만 (변수 불가)
    3. break 누락 시 fall-through
    4. default는 일치값 없을 때 실행

2. 반복문 (for, while, do~while)

  • for문: 횟수가 정해진 반복. `for(;;)`는 무한루프.
  • 탈출 후 변수값: `for(a=1;a<=5;a++)` 종료 후 `a`는 6!
  • while: 선검사 후실행 (0회 실행 가능).
  • do ~ while: 선실행 후검사 (무조건 최소 1회 실행). 문장 끝 세미콜론(`;`) 필수!

3. 이동문 (break, continue, goto)

  • break: 반복문 또는 switch 블록 완전 탈출. (중첩 루프 시 가장 가까운 1개만 탈출).
  • continue: 루프 탈출이 아님! 이번 회차 건너뛰고 다음 증감식/조건식으로 이동.
  • goto: 레이블 위치로 무조건 점프. 가독성 저해로 사용 비권장(지양).

1. 컴파일러 vs 인터프리터 비교

2. 반복문 3종 (for vs while vs do~while) 비교

구분 for문 while문 do ~ while문
주 사용 용도 횟수가 정해진 반복 조건에 따른 반복 조건에 따른 반복
조건 검사 시점 선(先) 조건 검사 선(先) 조건 검사 후(後) 조건 검사

끝 세미콜론(;) 없음 없음 while(조건); 필수!

3. 이동문 3종 (break vs continue vs goto) 비교

구분 break문 continue문 goto문
사용 가능한 곳 반복문 전체, switch문 반복문 전용 (switch 불가) 함수 내부 어디서나
실행 동작 루프 완전히 벗어나 탈출 이번 회차 건너뛰고 다음 반복 진행 지정된 레이블로 무조건 점프
이동 위치 해당 블록의 바깥 다음 줄 for: 증감식 / while: 조건식 레이블 위치
